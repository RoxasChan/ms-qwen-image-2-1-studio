提示词优化对话

先在右上角选类型：文生图提示词 走 Image Prompt Rewriting 规范，编辑图片提示词 走 Edit Prompt Enhancer 规范。编辑类需求要把图片锁定到对话里 —— 模型会真正"看"这些图再按规范改写， 所以保留声明是具体的（金色滚边、黄色盲道砖…），而不是笼统的"其余保持不变"。 需要「透明背景 / 抠图」类提示词时勾上 附加规则 —— 官方两份规范都没有覆盖这两件事， 附加规则是本项目自写的补充条款，以第二条 system 消息追加，官方规范原文一字不动。 每个对话独立保存，可新建、重命名、删除。
